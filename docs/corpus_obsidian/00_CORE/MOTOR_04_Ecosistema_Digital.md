# Motor QUIRA — El Ecosistema Digital

> El Motor nació para un municipio. Pero su lógica es universal: cualquier entidad territorial que planifique, ejecute, rindan cuentas y distribuya inversión puede ser evaluada con las mismas cinco preguntas. El ecosistema digital es esa universalización — el Motor que se multiplica sin perder su naturaleza.

## La Capa Raíz — QUIRA Gov

QUIRA Gov es la primera manifestación digital completa del Motor. No es un piloto — es la arquitectura de referencia sobre la que todo lo demás se construye.

### El Holding Montecristi como Laboratorio

```
QUIRA Gov — Montecristi (v1.0)

4 entidades          →    Motor único
GAD · Bomberos           TGI = 66.85
Aseo EP · Patronato      D1-D5 integrados

Presupuesto ≈54.24M  →    Score unificado
Inversión grupos 7+8      D3 = 59.85% ⚠️
25 metas PDyOT            ICPI = 69.93%
7 parroquias              IRS = 79.7
```

El holding municipal no es simplemente un conjunto de entidades — es el objeto de medición que prueba que el Motor funciona sobre estructuras institucionales complejas: con entes desconcentrados, con presupuestos independientes, con mandatos distintos, y con un único territorio que los integra.

## La Capa Aplicativa — Dashboard Streamlit

El Dashboard es la primera frontera entre el Motor y el mundo exterior. Es donde el TGI deja de ser un número en un Excel y se convierte en inteligencia navegable.

### Arquitectura de Visualización

```
TGI = 66.85 🟡 Transición con Riesgos
    ↓
Dashboard principal:
    ├── Barra TGI cantonal (semáforo)
    ├── Radar D1-D5 (perfil de gobernanza)
    ├── Mapa 7 parroquias (IRS por zona)
    └── Panel de alertas activas

Drill-down D3:
    ├── Devengado por ente (GAD · Bomberos · Aseo · Patronato)
    ├── Evolución mensual (curva de absorción)
    └── Simulador: ¿Qué pasa si D3 sube a 75%?

Drill-down D4:
    ├── Mapa de calor NBI vs inversión per cápita
    ├── Ranking parroquial IET
    └── Brecha USD ≈1.79M (visualización de cierre)
```

### El Dashboard como Interfaz Dialéctica

El Dashboard no es un fin — es un momento en el ciclo:

```
Motor calcula TGI     →    Dashboard lo muestra
Dashboard lo muestra  →    Autoridad toma decisión
Decisión modifica     →    Motor recalcula TGI
territorio
```

La actualización del Dashboard es el primer acto del retorno del Motor al territorio.

## La Capa de Escalabilidad — Los Cinco Módulos QUIRA

El TGI no es una metodología para Montecristi. Es una metodología para cualquier gobierno local que necesite saber si está gobernando bien su territorio. Los cinco módulos QUIRA son las cinco formas en que esa metodología se despliega en contextos distintos.

### QUIRA Gov — Gobernanza Municipal Integral

**Pregunta que responde:** ¿Está este municipio gobernando bien?

**Objeto de medición:** GAD + Holding Municipal (entes adscritos)

**Motor activo:** TGI 5D completo (D1-D5)

**Usuarios principales:** Alcaldía, Concejo, Dirección de Planificación, CPCCS, CGE

**Estado:** En producción — Montecristi v1.0

```
QUIRA Gov puede replicarse a cualquier GAD ecuatoriano
con el mismo framework TGI, adaptando:
    → Número de entes del holding
    → Metas del PDyOT local
    → Parroquias y NBI cantonal
    → Plan de Gobierno CNE específico
```

→ [[01_TGI_FRAMEWORK]] · [[02_TGI_DIMENSIONES]]

### QUIRA Funds — Cooperación Internacional y Financiamiento

**Pregunta que responde:** ¿Este municipio puede recibir y gestionar fondos de cooperación internacional con transparencia verificable?

**Diferencial metodológico:**
El TGI se convierte en el pasaporte de elegibilidad. Un municipio con TGI ≥75 tiene gobernanza verificada para acceder a financiamiento BID, GIZ, PNUD, CAF — con trazabilidad que los donantes pueden auditar.

**Indicadores adicionales:**
- Capacidad de absorción (derivado de D3)
- Equidad territorial (D4 como criterio de asignación)
- Transparencia institucional (D1+D5 como garantías)

**Estado:** En diseño metodológico

```
QUIRA Funds convierte el TGI en:
    ├── Score de elegibilidad para financiadores
    ├── Sistema de seguimiento de fondos externos
    └── Dashboard de rendición de cuentas a donantes
```

### QUIRA Audit — Transparencia Fiscal y Accountability

**Pregunta que responde:** ¿Las alertas del Motor se convierten en hallazgos auditables con trazabilidad legal?

**Diferencial metodológico:**
El silo D3 del Motor detecta sub-ejecución. QUIRA Audit transforma esa detección en expedientes auditables — cruzando eSIGEF con SERCOP con LOTAIP con resoluciones CGE.

**Conexión institucional:**
- D3=59.85% → Alerta QUIRA Audit → Auditoría interna GAD
- IRS=79.7 → Hallazgo QUIRA Audit → Informe CPCCS
- ICPI vs ICM (fricción=30.07pp) → Inconsistencia reportable → CGE

**Estado:** En diseño metodológico

```
QUIRA Audit convierte el Motor en:
    ├── Sistema de alerta temprana para auditores
    ├── Trazabilidad SERCOP ↔ eSIGEF ↔ PDyOT
    └── Expedientes pre-armados para CGE/CPCCS
```

### QUIRA Civic — Participación Ciudadana y Transparencia Activa

**Pregunta que responde:** ¿Sabe el ciudadano qué inversión llegó a su comunidad, cuánto se ejecutó, y qué alertas tiene activas su municipio?

**Diferencial metodológico:**
El TGI y sus dimensiones se traducen al lenguaje ciudadano. No "D3=59.85% de devengado en grupos 7+8" — sino "De cada $100 prometidos para obras, solo $60 se han ejecutado en tu cantón."

**Productos para ciudadanía:**
- Mapa de inversión por comunidad (D4 → IRS → por parroquia)
- Semáforo de ejecución por ente (D3 por entidad)
- Comparación promesas electorales vs ejecución (D2 → ICPI)
- Calendario de rendición de cuentas con preguntas sugeridas

**Conexión con participación formal:**
QUIRA Civic informa la Rendición de Cuentas anual que el CPCCS regula — los ciudadanos llegan con datos verificados del Motor.

**Estado:** En diseño de producto

```
QUIRA Civic convierte el Motor en:
    ├── Portal de transparencia activa cantonal
    ├── Herramienta de veeduría ciudadana
    └── Insumo para cabildos y RdC anuales
```

### QUIRA Climate — Adaptación Climática y Riesgo Territorial

**Pregunta que responde:** ¿La inversión municipal incorpora criterios de riesgo climático — y el territorio más vulnerable está recibiendo la inversión de adaptación que necesita?

**Diferencial metodológico:**
D4 (equidad territorial) se extiende con una dimensión adicional: el índice de vulnerabilidad climática por parroquia. La regresividad ya detectada (IRS=79.7) se cruza con la exposición a riesgo (inundaciones, sequías, deslizamientos) para revelar doble vulnerabilidad.

**Montecristi — Contexto específico:**
- Costa ecuatoriana: exposición a El Niño, inundaciones costeras
- Isabel Muentes: NBI=61.2% + vulnerabilidad climática = doble exclusión
- Brecha ≈1.79M ya identificada: parte de esos fondos debe tener destino climático

**Estado:** En diseño conceptual

```
QUIRA Climate convierte el Motor en:
    ├── Índice de inversión climáticamente sensible
    ├── Mapa de doble vulnerabilidad (NBI + riesgo)
    └── Herramienta de planificación resiliente
```

## La Capa de Conectividad — API Territorial

El Motor no tiene que vivir solo en el ecosistema QUIRA. La API Territorial es la interfaz que permite que el TGI fluya hacia otras plataformas de gobierno.

### Qué expone la API

```
GET /tgi/{canton_id}
    → TGI actual + dimensiones D1-D5
    → Alertas activas
    → Tendencia histórica (ciclos anteriores)

GET /tgi/{canton_id}/parroquias
    → IRS global
    → IET por parroquia
    → CN (Composite Need) por zona

GET /tgi/{canton_id}/simulate
    → Escenario: si D3 sube a X%, TGI proyectado = Y
```

### Consumidores potenciales de la API

| Plataforma | Uso del TGI |
|-----------|-------------|
| SIGAD / SETEPLAN | Score de gobernanza en reportes nacionales |
| BID / GIZ | Elegibilidad para fondos de cooperación |
| Portal CPCCS | Dashboard de RdC por GAD |
| Medios / sociedad civil | Visualizaciones de accountability |
| Otros QUIRA Gov | Comparativas inter-cantonales |

## La Lógica de Escalabilidad — Un Motor, Muchos Espejos

El insight central del ecosistema QUIRA es que el Motor no se replica — se *proyecta*:

```
Motor QUIRA
(SIAP-ICPI Gold Master)
        │
        ├── QUIRA Gov     → ¿Gobierna bien?
        ├── QUIRA Funds   → ¿Puede absorber cooperación?
        ├── QUIRA Audit   → ¿Tiene alertas auditables?
        ├── QUIRA Civic   → ¿El ciudadano puede entenderlo?
        └── QUIRA Climate → ¿Incorpora riesgo climático?
```

Cada módulo hace **la misma pregunta en su propio idioma**. El TGI es el traductor universal. La metodología no cambia — cambia el interlocutor.

> El Motor es como el ADN: una sola secuencia que se expresa de forma diferente en cada tejido — pero siempre con la misma lógica generativa.
