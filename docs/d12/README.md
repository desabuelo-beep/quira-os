## Arquitectura D12

D12 no es una campaña de "pedidos de datos".
Es un **programa estructurado de adquisición de evidencia** alineado con PD-GEN-01 y PD-GEO-01.

```
D12-A  Evidencia Interna GAD          → valida CAPACIDAD INSTITUCIONAL (20% género)
D12-B  Evidencia Territorial          → valida BRECHAS TERRITORIALES (80% género)
D12-C  Evidencia Externa              → valida GOBERNANZA Y COMPARABILIDAD
```

## Marco conceptual (PD-GEN-01 + PD-GEO-01)

El framing cambió respecto a versiones anteriores:

**Antes:**
> "Envíeme datos de género."

**Ahora (PD-GEO-01):**
> "Envíeme programas georreferenciados con cobertura territorial y beneficiarios por parroquia."

Porque toda brecha territorial debe poder representarse como:
1. **Indicador** — valor numérico comparable
2. **Narrativa** — explicación de gobernanza
3. **Entidad geoespacial** — capa en el GeoTwin del cantón
