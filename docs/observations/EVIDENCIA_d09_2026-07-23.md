## 2b · Hallazgo real: bug de sobrescritura + enricher no descubierto (OBS-014)

Al ejecutar `enrich_rdc.py` + `enrich_rdc_docx.py` para producir este mismo paquete de
evidencia, `git diff --stat data/gm_snapshot.json` mostró:

```
data/gm_snapshot.json | 1295 -------------------------------------------------
 1 file changed, 1295 deletions(-)
```

1295 líneas eliminadas, 0 insertadas — desproporcionado. **Se detuvo la operación de
inmediato** y se restauró con `git restore data/gm_snapshot.json` (no comiteado) antes de
investigar. `grep -rn '"aportes"' scripts/` reveló `scripts/enrich_aportes.py` — un tercer
enricher no encontrado en la Fase 1 (su nombre no calzaba `rdc|rendicion|accountab`).

**Causa raíz:** `enrich_rdc.py::main()` hacía `snap["rendicion"] = block` (sobrescritura
ciega de TODO el sub-objeto), en vez de fusionar como sí hacen `enrich_rdc_docx.py` y
`enrich_aportes.py`. Corregido a:
```python
rend = snap.get("rendicion") or {}
rend.update(block)
snap["rendicion"] = rend
```
Verificación post-fix: correr `enrich_rdc.py` solo ahora preserva `aportes` y `serie`
intactos — `git diff --stat data/gm_snapshot.json` → **sin cambios**. Detalle completo:
`docs/observations/OBS-014_Bug_Sobrescritura_Snapshot_RDC_y_Enricher_No_Descubierto.md`.
