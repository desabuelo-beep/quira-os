## ✅ DECISIONES CERRADAS

1. **TGI = Territorial Governance Intelligence** — framework propietario (Cat. B). El *score* territorial sí se muestra: "Gobernanza Territorial" (Inst) / "Estado del cantón" (Ciud).
2. **ICPI vs Salud Institucional — CERRADO (2026-06-14):** el **dominio d06** se llama **"Salud Institucional"**; el **índice** se llama **"Cumplimiento Institucional"**. El cajón es la salud; el número es el cumplimiento. *(Resuelve el pendiente de v1.)*
3. **TOP = Trayectoria Operativa Proyectada** — sigla interna; se muestra el concepto/semáforo → "Trayectoria de cumplimiento".
4. **AVEP** = baremo interno (Cat. B); el usuario ve la categoría en gobernanza, nunca la sigla.
5. **MMP** = hojas de monitoreo (fuente de resultados anuales · externo).
6. **Sigla vs nombre:** SOLO nombre en Institucional/Ciudadana; sigla permitida en pie técnico de Operaciones (rol interno Dylus).

## 🔍 HALLAZGOS DE AUDITORÍA (lo que la traducción reveló de los 12 ADN)

*La Tabla cumplió su función de auditoría (colega). Para ratificar en mesa:*

1. **d05 "Holding" es jerga corporativa débil para público.** Resuelto aquí: Institucional = "Empresas y Entidades del Municipio" · Ciudadana = "empresas públicas". El canónico "Holding e Integración Municipal" queda solo en Operaciones/CAF. **→ ratificar.**
2. **"Equidad" se usa en DOS sentidos** — IET (d10 · equidad *territorial*: reparto de servicios entre parroquias) vs d12 (Inclusión/Equidad/*Género*: grupos prioritarios). Riesgo de confusión. Desambiguación adoptada: d10 → "reparto justo entre parroquias"; d12 → "inclusión y equidad". **→ ratificar.**
3. **Macroeje 3 (d07·d08·d09) debe diferenciarse claro en lenguaje ciudadano:** Transparencia = *información publicada* · Participación = *voz de la gente* · Rendición = *cuentas de lo hecho*. Si no, el ciudadano los confunde. **→ vigilar al cosechar.**
4. **IOC** — nunca "opacidad" (acusatorio, viola Bloomberg en UI Institucional). Adoptado: "Transparencia pendiente" / "Información que falta publicar".
5. **d03 fuerte para CAF, llano para la calle:** "Gobernanza del Mandato" (CAF) ↔ "¿Cumple lo que prometió?" (Ciudadana). El concepto aguanta las dos alturas — buen indicio de solidez del ADN.
